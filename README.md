# 温江项目升级原型

独立的 Vue 3 + TypeScript + Vite + Arco Design 纯前端项目，继承融涞系统交互和布局。使用本项目模拟数据，新增或调整内容标红，每页提供简洁的产品需求说明。

## 运行与验证

Node.js 22.14+（22.x）或24+。命令串行执行：

```sh
npm ci
npm test
npm run build
npm run dev
```

开发及预览端口为5173，访问 `http://127.0.0.1:5173/`。默认首页为车辆线路日报，使用 Hash 路由及相对资源路径。`npm run preview` 用于预览构建结果，与开发服务任选一个运行。

## 产品逻辑

- 日报、月报、区域月报及明细均由同一份有效收运记录派生，异常原始记录不计入有效重量和桶数。行政区域仅保留街道。
- 线路为1—16号线；商户配置线路，车辆线路按当天实际停靠点模拟匹配最佳一条，不固定绑定车辆。
- 地磅配置开启后，车辆线路日报按日期＋车牌合计净重并计算准确率，最高100%。来源重量接入时统一换算kg。
- 联单配置开启后商户日报显示联单列，原型模拟近7天已结束日期的凌晨批次。一商户一天一份，编号为日期＋4位流水，机构内唯一。单页PDF可打印5份，重复下载不重新编号。
- 商户收集点使用真实高德底图和约200个模拟点位，支持聚合、街道筛选、线路着色、详情与地图编辑。

页面说明的源文件是 `src/mock/requirements.ts`；当前整理文档见 [产品需求说明](docs/product-requirements.md)。较早的现网审查、客户系统参考文档仅作历史依据。

## 高德地图与部署

本地配置写入已忽略的 `.env.local`，参照 `.env.example`：

- `VITE_AMAP_JS_KEY`：高德 JS API Key；兼容 `VITE_AMAP_KEY`。
- `VITE_AMAP_SECURITY_JS_CODE`：如该Key要求安全密钥，则配置此项。

构建时通过环境变量注入，源码不写实际Key。GitHub Actions 使用同名仓库 Secrets；本地地图可用不代表仓库已配置。高德底图需要联网，商户和收运数据仍为模拟数据。

日常开发使用 `dev`。合并到 `main` 后 GitHub Actions 自动部署 Pages；本轮检查不执行提交、推送或部署。
