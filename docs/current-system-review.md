## 可复用的优点

- 四类报表和桶数明细符合运营查账路径，主菜单概念清楚。
- 商户、收集点、桶各有独立档案；预警条件可配置，并有详情/视频/处理入口。
- 排班把班次、车辆和线路关联，批量创建前有预览。

## 主要改善点

- 表格较宽，重要业务列经常要横向滚动；将低频字段放详情，保留可点击桶数。
- 多处列表会先出现空表头/0值再完成加载，且发生一次长时间遮罩；正式开发需明确加载态与错误恢复，避免0被误认为真实统计。
- 原型上一版把经营状态、签约状态及点位RFID简化过度，本轮拆清模型。
- 没有计划时不要把完成率解释为0%，历史无计划快照不反推漏收。
