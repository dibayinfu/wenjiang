# 地磅与车辆收运比对需求

## 页面及操作

在现有页面结构中，在「作业监管 → 车辆收运汇总」扩展现有日期＋车牌列表，不另建重复页面。参考现网同名页面的日期、车辆、重量、桶数及计划点位习惯，沿用Arco交互。

新增列：地磅净重（kg）、准确率、差值（kg）、比对状态。净重可点击，抽屉展示同车同日每次过磅的称重流水、车牌号、皮重、毛重、净重、皮重时间、毛重时间等完整记录。原始地磅只读，不允许人工修改重量。原有收运明细、逐桶查看、日期范围、车辆筛选、分页、打印与导出保留，导出含新增比对列。

车辆汇总隐藏商户与收集点筛选，忽略其他页签遗留的局部条件，避免把部分商户收运量与整车过磅比较；关键词只搜索日期、车牌。其他报表仍支持商户与点位筛选。

## 数据字段

| 字段 | 说明 |
|---|---|
| 来源主机、来源记录ID | 幂等标识，防止重复同步累计 |
| 称重流水 | 来源系统的业务流水号，作为详情主要识别信息，不用平台记录ID冒充 |
| 平台记录ID | 详情追溯标识，与称重流水、来源记录ID分开 |
| 日期、皮重时间、毛重时间 | 北京时间，两个称重时刻独立保存；业务日期由完整过磅业务时间确定 |
| 车牌号 | 保留原始车牌，匹配时转大写、去空格和分隔符 |
| 皮重、毛重、净重 | kg，非负有限数；皮重＋净重＝毛重；净重为垃圾量 |
| 同步时间 | 平台接收记录时间，与过磅时间分开 |

## 比对口径

1. 按北京时间业务日期＋车牌，对有效收运重量求和，与相同日期和车牌的已同步地磅净重总和比较。同日多次进厂全部列出，不能只取最后一条。
2. **原型暂定准确率＝收运重量÷地磅净重×100%，保留两位小数。** 100%表示两套计量一致，98%表示收运计量比地磅少2%，102%表示高2%。这是计量比值，允许超过100%；不是采集成功率，也不是“1−绝对误差率”。正式验收前应确认业务口径。
3. 差值＝收运重量−地磅净重；正值偏高，负值偏低。单行按未舍入累计结果计算并显示两位小数，不能按明细准确率取平均。
4. 无地磅记录：显示「未同步」、准确率与差值为「—」。净重为0可点开详情，但准确率为「—」。毛皮净关系不成立的原始记录保留，标记异常，不输出正常准确率。
5. 当天标注「当日暂计」，因为收运和过磅尚可能增加。历史「已匹配」仅表示同日车牌匹配，不代表同步完整或差异已通过验收。
6. 本轮为日期级比对，未实现趟次配对和跨日调整。跨日收运/次日过磅、载荷未卸清、外来垃圾混装，都会影响日级比值，需按趟次或业务日期核验，不能据此直接考核设备精度。
7. 现有汇总以有收运的日期＋车辆为主表；仅有地磅、没有收运记录的孤立数据，正式版应进入待匹配清单，不应静默丢弃。原型暂不扩展独立待匹配工作台。

## 现场同步开发要求（非原型实际连接）

本地主机部署采集程序，以只读账号监测地磅数据库的新完成过磅记录，经出站加密连接上传远程平台。不得向现场数据库回写；数据库类型、表结构、主键、完成状态和单位需现场确认。

- 只同步完整毛重/皮重配对、已完成记录；数据库若先插入后补齐，应以更新时间＋主键游标或CDC追踪完成事件，不能只盯最大新增ID而漏掉补齐的数据。
- 以来源主机＋来源记录ID为幂等键；来源有多表/多地磅时需加来源表/设备命名空间。服务端持久化确认后再推进本地游标，失败重试、断网补传，重复上传不重复累计。
- 原始值及单位留存；同步时统一转kg，校验日期/车牌/重量/毛皮净关系。未知车辆、空车牌、冲正或异常记录进入待核验，不自动认领、不静默修正。
- 原始记录若允许补录/作废/冲正，应携带版本及状态，平台保留修订审计并按最新有效版本重算，避免将更新当成新的过磅。
- 记录采集心跳、最后成功同步时间、积压数量和失败原因；历史已匹配不等于数据完整，需现场日结或同步水位后才能标记最终比对。
- 主机数据库凭据仅保存在现场采集端，前端不保存密钥、不直接访问现场数据库。

## 原型范围与验证

所有记录位于src/mock，包含匹配、偏高、偏低、多次过磅、未同步和净重为0样例。地磅在初始化时生成独立快照，编辑模拟收运不会自动改变地磅，旧缓存补齐地磅样例并保留已有操作。原型不实现采集程序、远程接口或真实数据上传。

产品页面「产品需求说明」同步记载计算与交互规则。测试覆盖毛皮净守恒、多次合并、日期/车牌匹配、重复记录、零值/缺失/异常、准确率正负差异和独立快照。

## 山高系统字段参考补充

根据用户提供截图，地磅弹层逐条显示称重流水、车牌号、皮重、毛重、净重、皮重时间、毛重时间，重量统一标注kg。新增流水与两个时刻标红；每个流水保持独立，即使同车同日有多条，也不能只展示合计。皮重/毛重时间独立于平台同步时间，不用同步时间代替；正式数据未提供的字段显示待接入，不凭空反推。纯模拟旧缓存仅补齐可匹配样例的新增元信息，重量快照保持原样。业务流水沿用现场源值，去重仍按来源主机＋来源记录ID，不能默认流水跨主机全局唯一。截图中的真实流水与车辆不复制到模拟数据。

## 地磅设置最新页面

业务设置下采用列表，支持添加及编辑抽屉。字段仅所属机构（SaaS机构下拉）、数据来源（本地主机增量同步/云平台对接）、重量单位（千克/吨）、是否开启；移除地磅名称和同步方式只读字段。保存后生效，取消不修改；同机构只启用一个配置，切换需确认。保留旧配置迁移，原型选择来源单位不重算历史kg数据；正式接入按来源单位统一转kg。

最新准确率口径（替代前文比值口径）：以地磅净重为基准，准确率=max(0, 1−abs(收运重量−地磅净重)/地磅净重)×100%，取值0%—100%，两位小数。重量偏高/偏低对称扣减，完全一致100%，误差超过基准重量时为0%。地磅缺失/异常或净重为0仍不计算。列表、详情及导出统一使用此公式。
