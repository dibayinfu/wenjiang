# 作业监管升级范围

当前保留车辆线路日报、收运明细、商户日报、商户月报、区域月报五个独立页面。各页面说明统一维护在 `src/mock/requirements.ts`，完整口径见 [产品需求说明](product-requirements.md)。

- 车辆线路日报：最佳线路匹配、地磅净重及准确率。
- 收运明细：RFID查询、商户线路及收集点维护。
- 商户日报：线路、街道、状态、日均及每日联单。
- 商户月报：商户逐日重量矩阵、月合计、趋势及逐桶明细。
- 区域月报：街道逐日重量矩阵、月合计、对比及逐桶明细。

所有报表使用同源有效收运数据，重量保留两位小数。列表、汇总、图表及导出采用相同筛选条件。
